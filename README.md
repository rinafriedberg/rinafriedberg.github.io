# Rina Friedberg personal website

This is a plain static HTML/CSS version of the site.

## Files

- `index.html` — home
- `research.html` — selected public research
- `about.html` — short bio
- `cv.html` — embeds `cv.pdf`
- `style.css` — all styling

The site is designed to replace the old jemdoc-generated pages in the existing
`rinafriedberg.github.io` repository. Keep the existing `cv.pdf` and `bio.jpg`
when copying these files into the repository.

## Deploying

Copy these HTML/CSS files into the existing repository, replacing the old
`index.html`, `research.html`, and `code.html` pages as desired. Keep `cv.pdf`
and `bio.jpg`. Commit and push to the repository's current Pages branch.

No build step is required.
